One line under 200 characters that gets you out of work and gets a laugh. A judge model compares the lines in pairs and the top three split the pool.

`main.ts` writes a single funny sick-day excuse — one line, under 200 characters, half believable and with the twist landing at the end — to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), validating the 1–200 character gate first.

## Run it

```sh
node main.ts
```
